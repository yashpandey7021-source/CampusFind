# 🎓 CampusFind

### Your Campus. Your Community.

CampusFind is a simple and user-friendly **Campus Lost & Found Management Website** designed to help students report lost belongings and discover items found around their college campus.

🌐 **Live Demo:** [Visit CampusFind](https://campusfind-yey5.netlify.app/)

📂 **GitHub Repository:** [CampusFind](https://github.com/Abhinay2125S/CampusFind)

---

## ✨ Features

- **Home Page:** A central dashboard introducing the platform and displaying item listings.
- **Lost Items:** Browse items reported missing by students.
- **Found Items:** Explore items that have been found around campus.
- **Report an Item:** Submit a report for either a lost or found item.
- **Search Functionality:** Search listings by item name, description, or campus location.
- **Category Filters:** Filter items into different categories:
  - Electronics
  - ID Cards
  - Books / Notes
  - Keys
  - Personal Accessories
  - Other
- **Form Validation:** Required-field validation and user-friendly error messages.
- **Responsive Design:** Layout designed to work across different screen sizes.

## 🚀 Getting Started

Follow these steps to run CampusFind locally.

### 1. Clone the repository

```bash
git clone https://github.com/Abhinay2125S/CampusFind.git
```

### 2. Navigate to the project directory

```bash
cd CampusFind
```

### 3. Run the project

Open `index.html` in your preferred web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code.

No additional dependencies or package installations are required.

## 💻 How to Use

1. Open the CampusFind home page.
2. Browse the available lost and found item listings.
3. Navigate to the Lost Items or Found Items section.
4. Use the search bar to find a specific item.
5. Apply category filters to narrow down the results.
6. Navigate to Report an Item.
7. Select whether you lost something or found something.
8. Enter the item details, location, and relevant information.
9. Review the details and submit the report form.
